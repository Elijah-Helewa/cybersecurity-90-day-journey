# Linux CLI Basics Lab

## Objective

Practice navigating a Linux filesystem using the command line.

## Commands Used

- `pwd`
- `ls`
- `ls -l`
- `ls -a`
- `ls -al`
- `ls -1`
- `cd`
- `cd ..`
- `cd ~`
- `cat`

## What I Practiced

I practiced identifying my current working directory, listing directory contents, navigating between directories, returning to my home directory, and viewing the contents of text files.

## Key Concepts

### Root Directory

`/` represents the root of the Linux filesystem.

### Home Directory

`~` represents the current user's home directory.

### Current Working Directory

`pwd` displays the directory I am currently working in.

### Directory Navigation

`cd` allows me to change my current working directory.

## What I Learned

The Linux CLI allows users to interact with an operating system using text commands rather than a graphical interface.
